نظام الرقابة الصحية - النسخة 2

هذه النسخة تحفظ المعلومات القديمة ولا تستبدلها عند إضافة أي تحديث.
تتضمن البيانات القديمة الموجودة في النسخة السابقة، وأرشيفاً للملفات المرجعية المتاحة.

مبدأ العمل:
- قديم = يبقى محفوظاً كمرجع تاريخي.
- حديث = يضاف كنسخة جديدة ولا يحذف القديم.
- كل معلومة جديدة ينبغي ربطها بالمصدر والتاريخ ورقم الكتاب/التعليمات عند توفره.
- لا تعتبر قيمة قديمة نافذة حالياً إلا بعد التحقق من آخر كتاب/تعليمات رسمية.
